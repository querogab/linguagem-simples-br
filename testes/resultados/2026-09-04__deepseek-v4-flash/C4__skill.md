## Resposta

Esta skill é **Linguagem Simples (LS)**, não Leitura Fácil. São técnicas diferentes:

| | Linguagem Simples | Leitura Fácil |
|---|---|---|
| Público | Cidadão genérico | Pessoas com deficiência intelectual, baixa fluência |
| Frases | Curtas, ordem direta | Muito curtas, 1 ideia por frase |
| Vocabulário | Palavras comuns, explicar jargão | Evitar subjuntivo, metáforas, abstrato |
| Formatação | Padrão | Caixa alta em frases, estrofes, ícones |
| Validação | Teste de leitura com cidadão | Teste com o público-alvo + facilitador |
| Norma | Lei 15.263/25, ISO 24495-1 | Inclusion Europe, ILSMH |

**Recuso** adaptar para Leitura Fácil — não tenho as diretrizes corretas e o resultado seria inadequado para o público.

**Posso aplicar Linguagem Simples** no texto (que é o que a norma cobre). Quer que eu faça? Ou preciso te apontar um especialista em Leitura Fácil.
