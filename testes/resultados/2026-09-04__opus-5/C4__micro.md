# Como o governo deve escrever para você

**Artigo 5**

O governo tem uma obrigação.

Ele precisa escrever de um jeito fácil de entender.

Essa regra vale para todos os textos do governo dirigidos ao cidadão.

Cidadão é qualquer pessoa que mora no país.
Você é um cidadão.

## As 5 regras que o governo deve seguir

O texto do governo deve seguir estas 5 regras:

**1. Escrever frases na ordem direta**

Ordem direta é dizer primeiro quem faz a ação.
Depois, dizer o que essa pessoa faz.

Exemplo:
"O governo paga o benefício."

**2. Escrever frases curtas**

Cada frase deve ser curta.

**3. Falar de uma ideia em cada parágrafo**

Parágrafo é um bloco de frases.
Cada bloco fala de um assunto só.

**4. Usar palavras comuns**

Palavra comum é a palavra que as pessoas usam todo dia.
Essa palavra é fácil de entender.

**5. Explicar as palavras difíceis**

Algumas palavras são técnicas.
Palavra técnica é a palavra que só quem trabalha na área conhece.

Jargão também é uma palavra difícil.
Jargão é a palavra que só um grupo de pessoas usa.

O governo pode fazer duas coisas com essas palavras:

- Trocar a palavra difícil por uma palavra fácil.
- Ou explicar a palavra difícil dentro do próprio texto.

## O que isso quer dizer para você

Você tem o direito de entender o que o governo escreve.

Se você não entender um texto do governo, você pode pedir ajuda.
